Gabriel · Calidad y pruebas. Antes de entregar revisamos la seguridad contra tres amenazas: un empleado que intenta hacer más de lo que le toca, alguien con acceso a la computadora y una página web abierta en el mismo navegador. Clic: body-parser y qs tenían una falla que permitía tumbar el servidor con un pedido comprimido; se corrigió con npm audit fix y hoy el servidor tiene cero vulnerabilidades. Clic: el servidor no mandaba cabeceras de seguridad; ahora manda CSP solo con lo propio, nosniff y prohíbe que la app se abra dentro de un marco. Clic: react-router 6 tiene dos avisos, pero no se pueden explotar aquí: todas las rutas son fijas en el código y la app no se renderiza en un servidor. El arreglo es pasar a React Router 7, un cambio mayor que dejamos pendiente y lo decimos así.
